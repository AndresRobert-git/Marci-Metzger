# Marci Metzger Homepage Redesign

A responsive, single-page homepage concept for the Junior Website Builder assignment.

## Tools used
- HTML5 for page structure and accessible form controls
- CSS3 for layout, responsive breakpoints, typography, and visual styling
- Vanilla JavaScript for mobile navigation, current year, and email-prepared inquiry forms
- Google Fonts (Playfair Display and DM Sans)
- Unsplash-hosted images for temporary property photography

## Run locally
Open `index.html` in a browser. No build process or package installation is required.

## Design decision
The redesign uses a forest-green, warm-ivory, and sand palette with editorial serif headings. This creates a calm, premium real-estate feel and gives the photography room to lead, while the clear section hierarchy makes the page easier to scan.

## Important before submission
1. Review the original homepage and download its original images at full available resolution. Replace the temporary gallery/property images with the matching original assets where appropriate.
2. Check all content against the current reference page. Do not present stock photos as actual listings.
3. The property search is a visual inquiry form and does not connect to a listing database. It prepares an email instead.
4. The contact form opens the visitor's default email application; it does not send or store messages automatically.
5. Test the page at desktop, tablet, and mobile widths. Check the browser console and verify that all image URLs load.
6. Deploy the folder using GitHub Pages, Netlify, or another free static hosting service. Submit only the live website URL, not the repository URL.
